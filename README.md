# ⚡ Cybertron Store — Modern Footwear E-Commerce Platform

A high-performance, dark-mode footwear e-commerce application built with **Next.js (App Router)**, **Tailwind CSS**, and **Zustand**. Designed with a futuristic cyber aesthetic, dynamic product filtering, and instant state-driven shopping cart workflows.

## 🚀 Overview

**Cybertron Store** is crafted to deliver a fast, seamless shopping experience for premium sneakers and streetwear footwear. By leveraging client-side state handling with **Zustand** alongside **Next.js App Router**, the app ensures zero-lag cart operations, dynamic inventory filtering, and an immersive user interface.

---

## ✨ Key Features

- **Cyber Dark-Mode UI:** High-contrast, futuristic design tailored for modern streetwear brands.
- **Global Cart State Management:** Fast, lightweight state handling via **Zustand** with instant quantity updates and persistent cart sessions.
- **Interactive Product Catalog:** Filter sneakers by category, brand, size, and price without page reloads.
- **Product Detail Views:** Interactive size selector, multi-angle image previews, and dynamic stock status.
- **Responsive & Mobile-First:** Fluid layouts optimized across smartphones, tablets, and ultrawide displays.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React.js
- **State Management:** Zustand
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel

## 💻 Getting Started Locally

Follow these steps to run the project on your local development machine:

```bash
# 1. Clone the repository
git clone [https://github.com/AiyazMohammed25/cybertron-store.git](https://github.com/AiyazMohammed25/cybertron-store.git)

# 2. Navigate to the project directory
cd cybertron-store

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

Open http://localhost:3000 in your browser to view the application.
